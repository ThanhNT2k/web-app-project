## 🎯 Project Overview: CMC Truyện

### What is CMC Truyện?

**CMC Truyện** is a **modern Vietnamese online story reading platform** with:
- 📖 Full story management (upload, edit, organize chapters)
- 🔐 Secure user authentication with 4 role levels
- 📚 Advanced reading experience (dark mode, font sizing, auto-bookmark)
- 🤖 AI-powered chapter summaries (Google Gemini)
- 💬 Community features (comments, ratings, follow)
- ⭐ Smart recommendations based on reading history
- 📱 Fully responsive design (mobile, tablet, desktop)

### Target Users
- 📖 Story readers looking for ad-free reading
- ✍️ Story writers/uploaders for content distribution
- 👨‍💼 Administrators for platform management

### Key Differentiators
- ✨ **Zero Ads** in reading interface
- 🌙 **Dark Mode** with customizable settings
- 🤖 **AI Summaries** for quick chapter recall
- 💾 **Auto-Save** reading progress
- ⚡ **Fast Load Times** with proper optimization

---

## 🛠️ Technology Stack Explained

### Backend (Node.js + Express)
- **Node.js:** JavaScript runtime
- **Express.js:** Web framework for routing and middleware
- **PostgreSQL:** Relational database via Supabase
- **JWT:** Token-based authentication
- **bcryptjs:** Password hashing
- **Google Gemini API:** AI summaries

### Frontend (React + Tailwind)
- **React 18:** UI component library
- **React Router:** Page navigation
- **Tailwind CSS:** Utility-first styling
- **Bootstrap:** Responsive components
- **Axios:** HTTP requests to backend

### Database (PostgreSQL)
- 8 tables with proper relationships
- Indexed for fast queries
- Supports 4 user roles
- Audit trails with timestamps

### Deployment Ready
- **Backend:** Railway, Render, or Heroku
- **Frontend:** Vercel or Netlify
- **Database:** Supabase (PostgreSQL)
- **AI:** Google Gemini API

## 📞 Troubleshooting Guide

### If You Get Stuck
1. **Reread the step completely** - You might have missed something
2. **Check the Verification Checklist** - Verify all files exist
3. **Check error messages carefully** - They're very descriptive
4. **Ask Copilot to debug** - Paste error message and ask for help
5. **Check STEPS_QUICK_REFERENCE.md** - Look up similar patterns
6. **Compare with sample code** - Find what's different

### Common Issues
- **Port already in use** - Change PORT in .env
- **Database connection failed** - Check DATABASE_URL
- **JWT token expired** - Clear browser cache, login again
- **Styling not applying** - Rebuild Tailwind CSS
- **API not responding** - Check if backend server is running
